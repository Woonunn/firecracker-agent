# Agent Instructions

## Experience Log

Before you execute some jobs, read `experience.md` first. It records bugs and non-obvious traps that previous agents hit.

After running those jobs, update `experience.md` only when there is a new useful lesson: a bug encountered, an environment trap, a misleading result, a required cleanup step, or a fix that future agents are likely to miss. Do not record routine test results, benchmark numbers, or generic command output.
